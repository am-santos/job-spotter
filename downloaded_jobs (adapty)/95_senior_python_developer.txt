SUMMARY: This is a remote Senior Python Developer role at FunnelFox (Adapty), focusing on the Billing department. The engineer will be responsible for building, maintaining, and optimizing high-conversion web-to-app funnels, focusing heavily on payment processing, subscription management, and integration reliability using a modern async Python stack.

TECH STACK:
- Python
- FastAPI
- ClickHouse
- PostgreSQL
- Redis
- Kafka
- Docker
- Kubernetes
- asyncio
- aiohttp
- SQLAlchemy

REQUIREMENTS:
- Solid Python 3.8+ skills and ability to write clean, maintainable code.
- Comfortable with asyncio, FastAPI or aiohttp, PostgreSQL, and SQLAlchemy.
- Understanding and consistent application of software security principles.
- Enjoys chasing bottlenecks and optimizing performance.
- Experience working with payments like Stripe, Adyen, or PayPal (nice to have).
- Familiarity with Docker, Kubernetes, Redis, Prometheus, or Grafana (nice to have).

KEY RESPONSIBILITIES:
- Develop async processes with asyncio.
- Structure services using Domain-Driven Design (DDD).
- Build and maintain integrations with SSO, payment providers, and attribution pipelines.
- Improve reliability and availability for third-party integrations and app store API fetching.
- Set up payment processing and subscription management services.
- Write unit and integration tests to keep quality high.

SALARY: None

PERKS:
- Strong product with industry-best metrics (top 5% fastest-growing SaaS).
- Career growth opportunities (own critical areas, build a team).
- Direct communication and ownership (no bureaucracy/politics).
- Flexible remote work (work from anywhere).
- Benefits package (English lessons, sports reimbursements, laptop coverage, PTO, public holidays, and sick leave included as individual contractors).
