SUMMARY: Adapty is hiring an experienced Backend Developer to design and scale a high-load analytics platform for Apple Ads. The role involves deep integration with Apple APIs, asynchronous processing, complex business logic modeling using Domain-Driven Design (DDD), and optimizing systems built on a modern Python-based tech stack to ensure high performance and fault tolerance for global applications.

TECH STACK:
- Python
- FastAPI
- ClickHouse
- PostgreSQL
- Redis
- Kafka
- Docker
- Kubernetes
- Dramatiq
- Django (familiarity)

REQUIREMENTS:
- 5+ years of backend engineering experience with a strong Python background
- Expertise designing APIs that handle high-load, mission-critical traffic
- Solid hands-on experience with SQL/NoSQL databases
- Familiarity with FastAPI/Django and message brokers like Kafka or RabbitMQ
- Experience integrating with third-party APIs, especially Apple APIs (a plus)
- Proactive mindset: anticipate problems, propose better solutions, and make thoughtful trade-offs
- Demonstrate strong ownership and communication skills

KEY RESPONSIBILITIES:
- Design and develop a new high-load analytics platform for Apple Ads, powering dashboards and APIs for real-time campaign insights
- Work with queues and asynchronous processing (Dramatiq, Kafka), applying Domain-Driven Design (DDD) to model complex business logic and event flows
- Integrate deeply with Apple APIs to fetch ad metrics, campaign data, and subscription events, processing large volumes efficiently
- Enhance error handling, monitoring, and retries, and optimize communication with app stores through API-driven solutions
- Use a modern tech stack (Python, FastAPI, ClickHouse, PostgreSQL, Redis, Kafka, Docker, Kubernetes), ensuring high observability and fault tolerance
